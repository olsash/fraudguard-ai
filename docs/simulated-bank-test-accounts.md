# Simulated Bank Test Accounts

These credentials are for the local simulated academic environment only. They do not represent real bank accounts.

FraudGuard-AI generates development test credentials lazily for the currently authenticated user and selected bank. The generated account holder name comes from the signed-in user's `FullName` profile value. Account numbers, simulated IBANs, verification codes, account type, currency, and starting balance are generated by the backend and are different per user and bank.

Use the `Show Test Credentials` section in the Connect Bank Account dialog while running the frontend in development mode, or call the Development-only endpoint:

```http
GET /api/development/simulated-bank-credentials/{bankId}
```

The endpoint requires an authenticated `User` token and is unavailable outside the ASP.NET Core `Development` environment.
